# Contemporary NFT Artist Portfolio

A responsive, multi-page portfolio website for a contemporary NFT artist built with plain HTML, CSS, and vanilla JavaScript.

## Pages

- `index.html` - Home with full-screen hero, featured artwork, introduction, and navigation
- `about.html` - Biography, artist statement, and portrait section
- `collections.html` - NFT collections, artwork grid, descriptions, and marketplace links
- `exhibitions.html` - Chronological exhibition timeline
- `cv.html` - Exhibitions, awards, publications, education, and collections
- `contact.html` - Email and Instagram contact details

## Folder structure

```text
.
├── assets/
│   └── images/        # Replace placeholder SVGs with final portrait/artwork files
├── css/
│   └── styles.css     # Shared dark gallery theme and responsive layouts
├── js/
│   └── main.js        # Mobile navigation, header state, and reveal animations
└── *.html             # Portfolio pages
```

## Customization notes

Search each HTML/SVG file for `Replace` comments to find artist-specific content, image, marketplace, email, and social-profile placeholders.
